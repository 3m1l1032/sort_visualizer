# Sort Visualizer
See sorting algorithms as they work through sorting a list.

This is a learning project to be familiar with sorting algorithms and potentially GUI systems in C and C++. Since the goal here is to learn, no AI tools were used. Algorthims and workings are cited as needed.

Following "Introduction to Algorithms" Fourth Edition by Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein.
